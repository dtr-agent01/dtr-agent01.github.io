Privacy Policy

Last updated: November 2026

Hermes Agent ("the App") is a personal automation tool that accesses Google Workspace APIs (Drive, Gmail, Calendar, Sheets, Docs, Tasks) solely to perform actions explicitly requested by its owner.

Data We Access

The App accesses Google account data only when instructed by the authenticated user. This includes files, emails, calendar events, and documents belonging to that user's own Google account.

How We Use Data

Data is used only to execute the user's requests. We do not sell, share, or transfer any data to third parties.

Data Storage

The App does not store Google user data on any external server beyond short-lived local caches required for operation. OAuth credentials are stored locally on the owner's own machine.
